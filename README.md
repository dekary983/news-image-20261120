# The Day in One Picture — Friday 20 November 2026

A Node program (`main.ts`, standard library only) that procedurally draws a broadsheet front page summing up the world news of Friday 20 November 2026 and writes it to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). It is deterministic: every run writes identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
